# 最初の修正と確認範囲

2026-10-14。修正前コミット7b244ac。F01/F02の仕様案を基に今回の作業判断として実装した。本人の修正後レビューは未完了。

## 変更

- TaskMainで確認したgoalIdをLogicからDAOへ渡し、完了・名前編集・削除のSQL条件をIDとGOAL_IDの両方にした。
- DAOのbooleanをLogicで返し、失敗や対象不一致では画面に「対象タスクを変更できませんでした」を出す。登録失敗も画面へ伝える。
- 欠落/不正/負のtaskId、未知actionはエラー表示する。
- TitleInputで名前を共通検査。前後のCharacter.isWhitespaceまたはisSpaceCharに該当する空白を除去し、内部空白を保持。空白のみは拒否する。
- DBのVARCHAR(255)に合わせ、UTF-16で255単位を上限とする。通常の日本語は1単位、補助文字の絵文字等は2単位。上限超過は登録/変更前に拒否。

## 自動確認

Java25で全Javaソースとテストをコンパイル。H2 2.4.240の一時メモリDBのみを使い31項目合格。別目標と存在しないIDの3操作拒否、データ不変、正しい対象の3操作成功、空白種別・前後除去・日本語/ASCII/絵文字を含むDB文字数境界と保存結果を確認した。

初回テストではコードポイント数で上限判定すると絵文字255個がDB上限を超えたため、実測に合わせUTF-16単位に修正し再実行して合格。初回失敗を合格と扱わない。

本番の既存DBは変更していない。HTTP/セッション/JSP/実ブラウザによる自動検証はしていない。DB障害時の一覧nullや進捗0扱いは別課題で、この修正では解消していない。共通固定パスワード認証も未変更。

## あなたが行う手動再確認

1. Eclipseで本体を右クリック→リフレッシュ（F5）。サーバーを停止し、問題ビューの赤いエラーがないことを確認する。
2. H2は起動したまま、Tomcat11/Java25で再起動。以前開いたフォームは使わずGoalMainから画面を開き直す。
3. 専用目標の正しいタスクで名前編集・完了・削除を確認する。
4. 専用目標AのフォームのgoalIdはAのまま、taskIdだけを専用目標Bのタスクへ変えて送信する。編集・完了・削除の3種類ともエラーが表示され、BもAも変わらないことを確認する。削除確認用Bタスクが前テストでなくなっていれば新しい専用タスクを作る。
5. 目標登録・タスク登録/編集で空欄、半角空白のみ、全角空白のみを拒否することを確認する。
6. `　 確認A 　`を登録/編集し、前後空白を除いて保存され、名前の内部空白は保持されることを確認する。
7. ASCIIの255文字を受け付け、256文字をエラー表示で拒否することを確認する。必要な文字列は別PowerShellの `'a' * 255` / `'a' * 256` で作ってコピーできる。これは未実行の補助操作。
8. 基本機能テストの進捗0/50/33/100%、ログアウトと未ログイン制限も再確認し、各結果を報告する。

エラー時はそこで止め、工程・表示・コンソールの例外を残す。専用テストデータのみ使用する。Git上の修正保存と、実画面テスト合格は別に記録する。
