# 仮称：シンチョク — 目標・タスク管理アプリ

目標をタスクに分けて記録し、完了したタスクの割合を数値とバーで確認する、学習用Java Webアプリです。正式名称は未決定です。

『スッキリわかるサーブレット＆JSP入門 第5版』のサンプルアプリ「どこつぶ」を土台に、目標・タスク管理へ改造しています。現在は、就職活動用ポートフォリオとして品質・検証・設計資料を整備中です。

## 対象利用者と解決したい課題

資格試験合格など、数か月単位の目標に向けて、複数の教材やタスクに継続して取り組む人を対象としています。

次のような課題を解決することを目指しています。

- 教材やタスクごとの進み具合が分かりづらい
- 次に取り組む内容を判断しにくい
- 全体の進捗が見えづらく、達成感を得にくい
- 復習する対象やタイミングを把握しづらい

初回の完成範囲は、目標・タスク・完了・進捗の管理を、制作者が説明でき、主要な正常系・異常系を検証したローカルデモとして整えることです。復習管理や、学習内容・気づきを残す専用機能は初回範囲に含めず、次段階で検討します。

## 主な機能

| 機能 | 内容 |
|---|---|
| 目標管理 | 目標の登録・一覧表示 |
| タスク管理 | 目標ごとのタスク登録・一覧・名前編集・完了・削除 |
| 進捗表示 | 完了タスクの割合を数値とバーで表示 |
| ログイン・ログアウト | セッションを用いた学習用の簡易認証 |

認証は固定パスワードによる学習用実装です。ユーザー登録や、登録された本人であることを確認する認証は未整備です。

## 想定する利用場面

- 学習開始時：目標とタスクを確認し、次に取り組む内容を判断する
- 学習終了時：完了したタスクを更新し、進み具合を確認する

学習内容・気づきの記録、復習対象・タイミングの確認も要求として整理していますが、専用機能はまだ実装していません。

## 使用技術・構成

Java / Jakarta Servlet / JSP / JDBC / H2 Database / HTML

Eclipse・Pleiades / Tomcat / Git・GitHub

確認済みのプロジェクト設定と過去の環境確認では、Java25、Tomcat11、H2 2.4.240を使用しています。他環境での起動・DB初期化手順は整備中です。

```text
src/main/java/servlet/  リクエスト処理・画面遷移
src/main/java/model/    データモデル・処理ロジック
src/main/java/dao/      DBアクセス
src/main/webapp/        JSP・Web設定・ライブラリ
```

## 実装・検証状況

### main：修正前の基準版

基本操作10項目は、制作者が手動確認しました。

タスクIDと目標IDを同時に照合する修正に加え、名前の入力検査、失敗通知、回帰テストがあります。

- 過去の一時メモリH2によるDAO・入力処理の31チェックは合格

- 修正内容のレビューは実施済み
- 制作者による採否判断とmainへの統合は未完了

名前の長さは、利用者が見たままの文字数に近い方式で255文字までとする方針を採用しました。現在の修正ブランチは従来の内部的な数え方のままであり、入力検査・DB保存容量・テストの変更は未実施です。

31チェックの合格は、アプリ全体の安全性・正常動作を保証するものではありません。
