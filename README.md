# 仮称：シンチョク

目標と、その達成に向けたタスクを記録し、完了したタスクの割合を数値とバーで確認する学習用Webアプリです。参考書の「どこつぶ」を改造した作品です。正式名称は未決定です。

## 現在の機能

ソース上で確認した機能：目標登録・一覧、タスク登録・一覧・名前編集・完了・削除、進捗表示、ログイン・ログアウト。現行版の動作確認は未実施です。

## 開発状況

認証は学習用の固定パスワード判定です。ユーザー登録は未実装です。タスク変更対象と目標の対応照合に不足があり、改善対象として記録しています。

SQL/DDL、DB初期化資材、CSS/JS、テスト、起動手順は未作成で、これから整備します。既存のH2への接続処理はありますが、再現可能なDB準備手順は未整備です。

## 技術と実行方法

Java / Jakarta Servlet / JSP / JDBC / H2。Eclipse設定はJava25・Tomcat11、同梱H2 JARは2.4.240です。実稼働バージョンは未確認です。起動手順は準備中です。
