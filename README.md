# 仮称：シンチョク

目標とタスクを記録し、タスク完了の割合を数値とバーで確認するJava Webアプリです。参考書の「どこつぶ」を改造した作品で、正式名称は未決定です。

## 現在の機能と検証

目標登録・一覧、タスク登録・一覧・名前編集・完了・削除、進捗表示、ログイン・ログアウトがあります。修正前の基本操作10項目は制作者の手動確認で合格しました。

今回の修正では、タスク変更時にtaskIdとgoalIdを同時に照合し、失敗を画面へ伝えます。名前の前後空白を除去し、空白のみ・DB上限超過を拒否します。一時H2で31項目の自動確認が合格。修正後の実画面確認は未実施です。

## 技術と確認方法

Java25 / Jakarta Servlet / JSP / JDBC / H2 2.4.240 / Tomcat11 / Eclipse。実行環境とDB起動・初期化の完全な再現手順は整備中です。

PowerShellで `./test.ps1` を実行すると、本番のDBに接続せず一時メモリDBで回帰テストを行います。スクリプトのJava・TomcatのパスはPleiadesの現在の配置です。異なる環境ではパスを調整してください。

修正仕様・検証範囲・手動再確認は [docs/FIRST_FIX.md](docs/FIRST_FIX.md) を参照してください。
