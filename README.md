# 仮称：シンチョク — 目標・タスク管理アプリ

目標をタスクに分けて記録し、完了したタスクの割合を数値とバーで確認する、学習用Java Webアプリです。学習や資格勉強などの作業と進み具合を整理する用途を想定しています。正式名称は未決定です。

『スッキリわかるサーブレット＆JSP入門 第5版』のサンプルアプリ「どこつぶ」を土台に改造しています。現在は就職活動用ポートフォリオとして、品質・検証・説明資料を整備中です。

## 教材と追加・変更した内容

使用教材：

- 書名：『スッキリわかるサーブレット＆JSP入門 第5版』
- 著者：国本大悟
- 監修：株式会社フレアリンク
- 出版社：インプレス
- 公式サイト：https://sukkiri.jp/books/sukkiri_servlet5/

書籍を購入し、掲載コードを手入力して学習しました。Servlet・JSP・セッション等の構成を基礎に、次の内容を追加・変更してきました。

- 投稿管理から目標・タスク管理への変更
- 目標とタスクの1対多のデータ管理
- タスク名の編集・完了・削除
- 完了タスク数に基づく進捗率の計算とバー表示
- ログイン名による目標の絞り込みと、目標へのアクセス確認

ファイル単位での教材由来部分と追加部分の詳細な照合は整理中です。すべてをゼロから独自に実装した作品ではありません。

## 主な機能

| 機能 | 内容 |
|---|---|
| 目標管理 | 目標の登録・一覧表示 |
| タスク管理 | 目標ごとの登録・一覧・名前編集・完了・削除 |
| 進捗表示 | 完了割合を数値とバーで表示 |
| ログイン・ログアウト | セッションを用いた学習用の簡易認証 |

認証は固定パスワードによる学習用実装です。ユーザー登録や本人認証は未整備です。

## 使用技術・構成

Java / Jakarta Servlet / JSP / JDBC / H2 Database / HTML

Eclipse・Pleiades / Tomcat / Git・GitHub

過去の環境確認ではJava25、Tomcat11、H2 2.4.240を使用しています。他環境での起動・DB初期化手順は整備中です。

```text
src/main/java/servlet/  リクエスト処理・画面遷移
src/main/java/model/    データモデル・処理ロジック
src/main/java/dao/      DBアクセス
src/main/webapp/        JSP・Web設定・ライブラリ
```
